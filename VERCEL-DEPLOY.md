# Sash Mandi Darbar Billing Software - Vercel Deployment

This ZIP is structured for Vercel deployment from the repository root.

Vercel settings:
- Framework Preset: Vite
- Root Directory: leave empty / `./`
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`

Do not add a `rootDirectory` property to `vercel.json`.
